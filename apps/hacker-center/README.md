# Central de Hacker

Painel opcional para aprendizado de segurança, CTFs e testes em ambientes próprios ou explicitamente autorizados.

## MVP 0.1

- Redes: Nmap, traceroute, DNS
- Análise de tráfego: Wireshark/tcpdump
- Terminal de laboratório
- Catálogo de ferramentas opcionais
- Relatórios locais de laboratório

## Princípios

- Ferramentas pesadas não vêm todas instaladas por padrão.
- Instalação sob demanda para preservar RAM e disco.
- A interface deve deixar claro o escopo autorizado do laboratório.
- Nenhuma credencial, chave ou segredo é armazenado em texto puro.
