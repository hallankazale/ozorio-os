# Branding — Ozorio OS

## Direção visual

- Inspiração funcional: Windows 7, sem copiar marcas, logotipos ou assets proprietários.
- Identidade própria: símbolo circular do Ozorio OS.
- Paleta: azul-marinho como base, roxo como destaque principal e verde/teal como acento.
- Gradientes controlados; evitar excesso de cores saturadas simultâneas.
- Efeito de vidro e profundidade com parcimônia para preservar desempenho.

## Telas de referência

1. Splash / boot
2. Login
3. Desktop principal
4. Menu principal
5. Central de Desenvolvimento
6. Central de Hacker
7. Configurações
8. Instalador

## Regras de performance

- Evitar wallpapers animados.
- Evitar blur em tempo real quando houver alternativa estática.
- Ícones em SVG/PNG otimizados.
- Sombras leves e poucos efeitos de composição.
- Meta inicial: desktop em repouso abaixo de 600 MB de RAM no hardware de referência.
