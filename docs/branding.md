# Branding Aurora

O branding do Ozorio OS é aplicado pelo script `scripts/install-branding.sh` durante a geração da ISO Live.

## Princípios

- visual inspirado em interfaces desktop clássicas, sem copiar marcas proprietárias;
- paleta restrita em roxo, azul-marinho e verde;
- assets vetoriais leves;
- sem blur ou transparências pesadas;
- compatível com GPUs antigas e PCs de pouca memória.

## Componentes

- logo: `branding/logo/ozorio-logo.svg`
- wallpaper: `branding/wallpaper/ozorio-aurora.svg`
- tema Openbox: `branding/theme/aurora/openbox/themerc`
- cores: `branding/theme/aurora/colors.conf`
- login: `configs/desktop/lightdm-gtk-greeter.conf`
- painel e atalhos: `branding/desktop/`
